# Kernel AI

Kernel AI 是一个基于 Electron + Vite + Vue3 + JavaScript 的 Linux 服务器连接工具。它把 SSH 连接、远程文件管理、在线编辑、终端会话和 OpenAI-compatible 大模型配置放在同一个桌面应用里，方便在本地管理远程 Linux 环境。

## 功能

- 服务器连接配置与测试
- 远程文件列表浏览
- 文件内容读取、编辑与保存
- 文件上传、下载和拖拽上传入口
- 远程终端会话
- Kernel AI 对话面板
- OpenAI-compatible 模型配置：Base URL、API Key、Model
- Vue Router 页面路由
- Pinia 工作台状态管理

## 环境要求

- Node.js：建议使用当前 LTS 版本
- pnpm：项目使用 `pnpm@9.15.4`
- 可访问的 Linux 服务器：需要开启 SSH，并准备好账号密码或私钥

首次拉取项目后安装依赖：

```bash
pnpm install
```

## 目录

- `src/views`：页面级视图
- `src/components`：侧栏、服务器配置、文件列表、编辑器、AI 面板等组件
- `src/stores`：Pinia 状态和业务动作
- `src/router`：Vue Router 路由配置
- `electron/backend`：Node 后台服务、IPC 注册、本地配置仓库

## 开发运行

```bash
pnpm dev
```

启动后会打开 Electron 桌面窗口，默认进入“服务器”页面。

## 构建

```bash
pnpm build
```

构建产物说明：

- `dist`：前端页面产物
- `dist-electron`：Electron 主进程和 preload 产物

## 打包

```bash
# 生成当前系统的未压缩应用目录，用于本地快速检查
pnpm pack:dir

# 打包 macOS 安装包，产物输出到 release 目录
pnpm dist:mac

# 打包 Windows 安装包，产物输出到 release 目录
pnpm dist:win
```

说明：`dist:mac` 和 `dist:win` 会先执行 `pnpm build`，再通过 `electron-builder` 生成平台安装包。跨平台打包可能受系统能力限制，例如 macOS 安装包通常需要在 macOS 上生成。

打包产物默认输出到 `release` 目录。

## 使用说明

### 1. 添加服务器

1. 进入左侧“服务器”页面。
2. 点击新增服务器入口。
3. 填写服务器信息：
   - `IP 地址/主机名`：远程服务器地址。
   - `端口`：默认 `22`。
   - `用户名`：默认 `root`，可改成实际登录用户。
   - `认证方式`：支持密码或私钥。
4. 点击连接，应用会测试 SSH 连通性。
5. 连接成功后，服务器配置会保存到本地，下次启动可继续使用。

### 2. 连接已有服务器

在“服务器”页面点击服务器卡片，应用会发起 SSH 连接。连接成功后会进入文件管理页面；如果连接失败，弹窗里会显示失败原因和连接日志。

服务器卡片会显示在线、离线、检测中等状态。进入管理模式后，可以选择服务器并进行删除等管理操作。

### 3. 浏览和编辑远程文件

连接服务器后进入左侧“文件列表”页面，可以进行以下操作：

- 在路径输入框中输入远程路径并跳转。
- 点击目录展开或进入目录。
- 点击文件打开内容。
- 在编辑器里修改文件后点击保存。
- 点击上传按钮选择本地文件上传。
- 将本地文件拖到上传区域进行拖拽上传。
- 点击下载按钮下载选中文件。
- 使用刷新按钮重新读取当前目录。

文件保存会直接写回远程服务器，请确认当前连接账号具备对应路径的读写权限。

### 4. 使用远程终端

文件管理页面内置终端区域。连接服务器后，应用会基于当前 SSH 信息创建终端会话，可以直接执行常用 Linux 命令。关闭连接或离开会话时，终端监听会被清理。

### 5. 配置大模型

进入左侧“大模型配置”页面，按 OpenAI-compatible 协议填写模型服务：

1. `Provider`：配置名称，例如 `OpenAI`、`DeepSeek`、`Qwen`。
2. `Base URL`：接口地址，通常以 `/v1` 结尾，例如 `https://api.openai.com/v1`。
3. `API Key`：模型服务密钥。
4. 点击“连接并获取模型”，应用会请求 `/models` 获取可用模型列表。
5. 选择当前聊天模型后点击“保存配置”。

保存后，AI 面板会使用当前选中的模型配置。

### 6. 本地配置文件

服务器和模型配置会保存到本地配置目录。开发阶段项目里可能出现 `servers_config` 目录，用于保存本地调试配置。该目录包含敏感连接信息时，不要提交到代码仓库。

## 常见问题

### 连接服务器失败

- 检查服务器 IP、端口、用户名是否正确。
- 确认服务器 SSH 服务已启动。
- 使用密码登录时，确认密码没有过期。
- 使用私钥登录时，确认私钥路径可访问；如果私钥带口令，可在密码字段填写私钥口令。
- 确认本机网络可以访问目标服务器端口。

### 文件无法保存

- 确认当前登录用户对目标文件有写权限。
- 确认目标文件没有被系统权限或只读挂载限制。
- 尝试保存到用户目录下的普通文件，排除权限问题。

### 打包失败

- 先执行 `pnpm install` 确保依赖完整。
- macOS 打包时如果没有签名证书，可能会跳过签名，只适合本地测试。
- Windows 安装包建议在 Windows 环境或 CI 中验证。
- 如果原生依赖 rebuild 失败，先确认本机具备 Node.js 原生模块编译环境。

## 连接说明

当前主进程通过纯 Node 的 `ssh2` 和 `ssh2-sftp-client` 执行远程连接与文件操作，开发和打包后使用同一套后台逻辑。服务器表单支持两种认证方式：用户名 + 密码，或用户名 + 私钥路径；如果私钥本身带口令，可继续填写密码字段作为私钥口令。
